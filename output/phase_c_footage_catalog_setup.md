## Three Tiers Explained

### Tier 1 — CREATOR_AUTHORIZED
A YouTube creator gives explicit written permission for Beyond The Pitch to use their footage.

**Default status:** `NOT_APPROVED`  
**How to approve:**
1. Import the asset: `import stock` or `request-permission`
2. Send the email/DM manually (the CLI prints a template)
3. Receive written reply from creator
4. Run `confirm-permission --evidence "Their exact words"`

**Never auto-approved.** A creator's video being public is not permission.

### Tier 2 — STOCK_LICENSED
Footage from Pixabay, Pexels, or Coverr.

**Default status:** `PENDING_REVIEW` (license is auto-inferred from domain)  
**How to approve:**
1. Import: `python scripts/footage_catalog.py import stock --url URL --description DESC`
2. Download the actual clip and visually inspect: no identifiable players in a negative context, no club logos or broadcast branding
3. If clean: `python scripts/footage_catalog.py approve --id UUID`

### Tier 3 — AI_GENERATED
Clips generated by Kling, Runway, or similar on a paid commercial plan.

**Default status:** `PENDING_REVIEW`  
**How to approve:**
1. Generate the clip on a paid plan (Kling Standard minimum)
2. Import: `python scripts/footage_catalog.py import ai --tool kling --plan-tier standard --prompt "..." --local-path FILE --duration 5.0`
3. Review the output: confirm no real player likenesses, no brand logos
4. Approve: `python scripts/footage_catalog.py approve --id UUID`
5. At YouTube upload: toggle "Contains AI-generated content" in YouTube Studio

---

## Hard Gate Rule

An asset must have ALL THREE before entering video production:
- `approval_status == APPROVED`
- `commercial_use == True`
- `monetization_allowed == True`

Calling `gate.check_all([asset_id, ...])` raises `FootageGateError` immediately if any asset fails. This runs before any render.

**What never satisfies the gate:**
- YouTube public availability
- Visible watermark
- Credit in description
- Editing or transforming the clip
- Assuming a CC license without reading the actual file's license page

## Quick Start

```bash
# Activate venv
source venv/bin/activate

# Check a URL's license before importing
python scripts/footage_catalog.py check --url "https://pixabay.com/videos/CLIP-ID/"

# Import a Pixabay clip
python scripts/footage_catalog.py import stock \
    --url "https://pixabay.com/videos/soccer-sports-event-stadium-arena-8502/" \
    --description "Stadium crowd aerial, 1080p" \
    --tags stadium crowd football \
    --creator-name "Dieter_G"

# After visual inspection confirms no logos/identifiable faces:
python scripts/footage_catalog.py approve --id UUID

# Import an AI clip after generating it on Kling Standard
python scripts/footage_catalog.py import ai \
    --tool kling \
    --plan-tier standard \
    --prompt "Cinematic penalty spot, wet grass, stadium floodlights, 9:16 vertical, no players" \
    --local-path output/footage/penalty_spot_test.mp4 \
    --duration 5.0

# List all assets
python scripts/footage_catalog.py list
python scripts/footage_catalog.py list --tier STOCK_LICENSED --status APPROVED
```
